# mv3d_rgbd_ros 功能包使用说明

## 功能包概述

`mv3d_rgbd_ros` 是一个基于海康威视 Mv3dRgbdSDK 的 ROS 功能包，用于连接和控制海康威视 3D RGB-D 相机，支持图像和点云数据的采集、发布、订阅和保存。

### 主要功能

1. **图像采集与发布**：支持深度图、RGB 图、左/右 IR 图像的采集和 ROS 话题发布
2. **点云采集与保存**：支持多种点云格式的采集和保存（PCD 格式）
3. **多相机支持**：支持通过序列号连接指定相机，支持多相机同时工作
4. **服务通信**：提供 ROS Service 接口，支持客户端-服务器模式的数据传输

## 可执行文件说明

功能包包含以下可执行文件：

| 可执行文件 | 功能 | 说明 |
|-----------|------|------|
| `hik_camera_image_pub` | 图像发布节点 | 从相机采集图像并发布到 ROS 话题 |
| `hik_camera_image_sub` | 图像订阅节点 | 订阅图像话题并保存到本地 |
| `hik_camera_image_client` | 图像服务客户端 | 通过服务发送图像数据 |
| `hik_camera_image_server` | 图像服务服务器 | 接收图像服务请求并保存图像 |
| `hik_camera_point_cloud_client` | 点云服务客户端 | 通过服务发送点云数据 |
| `hik_camera_point_cloud_server` | 点云服务服务器 | 接收点云服务请求并保存点云 |

### 发布的 ROS 话题

**图像发布节点 (`hik_camera_image_pub`) 发布的话题：**

| 话题名称 | 消息类型 | 说明 |
|---------|---------|------|
| `/camera/depth` | `sensor_msgs/Image` | 深度图像（16位） |
| `/camera/rgb` | `sensor_msgs/Image` | RGB 彩色图像 |
| `/camera/leftIr` | `sensor_msgs/Image` | 左目红外图像 |
| `/camera/rightIr` | `sensor_msgs/Image` | 右目红外图像 |
| `/depthCamInfo` | `sensor_msgs/CameraInfo` | 深度相机标定信息 |
| `/rgbCamInfo` | `sensor_msgs/CameraInfo` | RGB 相机标定信息 |

### 提供的 ROS 服务

| 服务名称 | 服务类型 | 说明 |
|---------|---------|------|
| `SaveImage` | `mv3d_rgbd_ros/image` | 保存图像服务 |
| `SavePointCloud` | `mv3d_rgbd_ros/pointcloud` | 保存点云服务 |

## Launch 文件详解

### 1. capture_and_save.launch

**功能：** 最简单的图像采集和保存示例，使用发布-订阅模式。

**启动的节点：**
- `hik_camera_image_pub`：图像发布节点
- `hik_camera_image_sub`：图像订阅节点（自动保存图像）
- `rviz`：可视化工具

**使用方法：**
```bash
roslaunch mv3d_rgbd_ros capture_and_save.launch
```

**工作流程：**
1. `hik_camera_image_pub` 连接相机（默认连接第一个可用相机）
2. 以 30Hz 频率采集并发布图像到话题
3. `hik_camera_image_sub` 订阅话题，接收图像并保存到 `image/` 目录
4. Rviz 自动打开，可以可视化图像

**保存的文件：**
- `image/[帧号]_DepthImage.png` - 深度图
- `image/[帧号]_RgbImage.png` - RGB 图
- `image/[帧号]_LeftIrImage.png` - 左目 IR 图
- `image/[帧号]_rightIrImage.png` - 右目 IR 图

**特点：**
- ✅ 最简单易用
- ✅ 自动连接第一个相机
- ✅ 自动保存所有图像类型
- ❌ 不支持指定相机序列号

### 2. connect_by_serial_number.launch

**功能：** 通过指定序列号连接特定相机，使用发布-订阅模式。

**启动的节点：**
- `hik_camera_image_pub`：图像发布节点（可指定序列号）
- `hik_camera_image_sub`：图像订阅节点
- `rviz`：可视化工具

**使用方法：**

**方式 1：使用默认参数（连接第一个相机）**
```bash
roslaunch mv3d_rgbd_ros connect_by_serial_number.launch
```

**方式 2：指定相机序列号**
```bash
roslaunch mv3d_rgbd_ros connect_by_serial_number.launch cam_sn1:=你的相机序列号
```

**参数说明：**
- `cam_sn1`：相机序列号（字符串），默认为 `"None"`（连接第一个相机）

**示例：**
```bash
# 连接序列号为 "HK12345678" 的相机
roslaunch mv3d_rgbd_ros connect_by_serial_number.launch cam_sn1:=HK12345678
```

**工作流程：**
1. 根据参数 `cam_sn1` 连接指定相机（如果为 "None" 则连接第一个）
2. 发布图像到话题
3. 订阅节点保存图像
4. Rviz 可视化

**特点：**
- ✅ 支持指定相机序列号
- ✅ 适合多相机环境
- ✅ 自动保存图像
- ✅ 可视化支持

**如何获取相机序列号？**

运行发布节点时会自动枚举并显示所有可用相机的序列号：
```bash
rosrun mv3d_rgbd_ros hik_camera_image_pub
```

输出示例：
```
Index[0]. SerialNum[HK12345678] IP[192.168.1.100] name[相机型号].
Index[1]. SerialNum[HK87654321] IP[192.168.1.101] name[相机型号].
```

### 3. multiple_camera.launch

**功能：** 同时连接和控制多个相机，使用服务通信模式（客户端-服务器）。

**启动的节点：**
- `hik_camera_image_client1`：第一个相机的服务客户端
- `hik_camera_image_client2`：第二个相机的服务客户端
- `hik_camera_image_server`：图像服务服务器（保存图像）

**使用方法：**

**方式 1：使用默认参数（两个客户端都连接第一个相机）**
```bash
roslaunch mv3d_rgbd_ros multiple_camera.launch
```

**方式 2：指定两个相机的序列号**
```bash
roslaunch mv3d_rgbd_ros multiple_camera.launch cam_sn1:=HK12345678 cam_sn2:=HK87654321
```

**方式 3：只指定第一个相机**
```bash
roslaunch mv3d_rgbd_ros multiple_camera.launch cam_sn1:=HK12345678
```

**参数说明：**
- `cam_sn1`：第一个相机的序列号，默认为 `"None"`
- `cam_sn2`：第二个相机的序列号，默认为 `"None"`

**工作流程：**
1. `hik_camera_image_server` 启动，等待服务请求
2. `hik_camera_image_client1` 和 `client2` 分别连接各自的相机
3. 客户端以 30Hz 频率采集图像，通过 `SaveImage` 服务发送给服务器
4. 服务器接收图像并保存到 `image/` 目录

**通信模式：**
```
相机1 → client1 → SaveImage 服务 → server → 保存图像
相机2 → client2 → SaveImage 服务 → server → 保存图像
```

**特点：**
- ✅ 支持多相机同时工作
- ✅ 使用服务通信，更可靠
- ✅ 服务器统一保存，便于管理
- ✅ 每个客户端独立控制自己的相机

**适用场景：**
- 多相机同步采集
- 需要统一的数据保存管理
- 网络分布式采集

### 4. obtain_point_cloud.launch

**功能：** 采集和保存点云数据，使用服务通信模式。

**启动的节点：**
- `hik_camera_point_cloud_client`：点云服务客户端
- `hik_camera_point_cloud_server`：点云服务服务器（保存点云）

**使用方法：**

**方式 1：使用默认参数**
```bash
roslaunch mv3d_rgbd_ros obtain_point_cloud.launch
```

**方式 2：指定点云类型和相机序列号**
```bash
roslaunch mv3d_rgbd_ros obtain_point_cloud.launch pd_type:=1 cam_sn1:=HK12345678
```

**参数说明：**
- `pd_type`：点云类型（整数），可选值：
  - `1`：基础点云（PointXYZ）- 只有 XYZ 坐标
  - `2`：带法向量的点云（PointNormal）- XYZ + 法向量
  - `3`：带颜色的点云（PointXYZRGB）- XYZ + RGB 颜色
  - `4`：带颜色和法向量的点云（PointXYZRGBNormal）- XYZ + RGB + 法向量
  - 默认值：`1`
- `cam_sn1`：相机序列号，默认为 `"None"`

**点云类型说明：**

| 类型 | 值 | 点云格式 | 包含信息 | 文件大小 |
|------|---|---------|---------|---------|
| 基础点云 | 1 | `pcl::PointXYZ` | X, Y, Z | 最小 |
| 带法向量 | 2 | `pcl::PointNormal` | X, Y, Z, 法向量, 曲率 | 中等 |
| 带颜色 | 3 | `pcl::PointXYZRGB` | X, Y, Z, R, G, B | 较大 |
| 完整点云 | 4 | `pcl::PointXYZRGBNormal` | X, Y, Z, R, G, B, 法向量, 曲率 | 最大 |

**工作流程：**
1. `hik_camera_point_cloud_server` 启动，等待服务请求
2. `hik_camera_point_cloud_client` 连接相机
3. 客户端设置点云输出类型（根据 `pd_type` 参数）
4. 客户端以 30Hz 频率采集点云，通过 `SavePointCloud` 服务发送给服务器
5. 服务器接收点云并保存为 PCD 文件到 `point_cloud/` 目录

**保存的文件：**
根据点云类型，保存为不同的 PCD 文件：
- `point_cloud/[帧号]_point_cloud.pcd` - 类型 1
- `point_cloud/[帧号]_point_cloud_with_normals.pcd` - 类型 2
- `point_cloud/[帧号]_textured_point_cloud.pcd` - 类型 3
- `point_cloud/[帧号]_textured_point_cloud_with_normals.pcd` - 类型 4

**特点：**
- ✅ 支持多种点云格式
- ✅ 使用服务通信，数据可靠
- ✅ 自动保存为 PCL 标准格式（PCD）
- ✅ 支持指定相机序列号

**使用示例：**

```bash
# 采集基础点云（只有 XYZ 坐标）
roslaunch mv3d_rgbd_ros obtain_point_cloud.launch pd_type:=1

# 采集带颜色的点云
roslaunch mv3d_rgbd_ros obtain_point_cloud.launch pd_type:=3 cam_sn1:=HK12345678

# 采集完整点云（带颜色和法向量）
roslaunch mv3d_rgbd_ros obtain_point_cloud.launch pd_type:=4
```

## 完整使用流程示例

### 示例 1：单相机图像采集

```bash
# 1. 启动图像采集和保存
roslaunch mv3d_rgbd_ros capture_and_save.launch

# 2. 图像会自动保存到当前目录的 image/ 文件夹
# 3. Rviz 会自动打开，可以查看实时图像
```

### 示例 2：指定相机采集图像

```bash
# 1. 先运行一次，查看可用相机序列号
rosrun mv3d_rgbd_ros hik_camera_image_pub

# 2. 使用序列号启动
roslaunch mv3d_rgbd_ros connect_by_serial_number.launch cam_sn1:=HK12345678
```

### 示例 3：多相机同步采集

```bash
# 启动多相机采集（需要至少两个相机）
roslaunch mv3d_rgbd_ros multiple_camera.launch cam_sn1:=HK12345678 cam_sn2:=HK87654321

# 图像会保存到 image/ 目录，文件名包含帧号
```

### 示例 4：点云采集

```bash
# 采集带颜色的点云
roslaunch mv3d_rgbd_ros obtain_point_cloud.launch pd_type:=3 cam_sn1:=HK12345678

# 点云会保存到 point_cloud/ 目录
```

## 数据保存位置

### 图像数据
- **保存路径：** 运行 launch 文件时的当前工作目录下的 `image/` 文件夹
- **文件格式：** PNG 图像文件
- **命名规则：** `[帧号]_图像类型.png`

### 点云数据
- **保存路径：** 运行 launch 文件时的当前工作目录下的 `point_cloud/` 文件夹
- **文件格式：** PCD（PCL 点云数据格式）
- **命名规则：** `[帧号]_点云类型.pcd`

## 参数配置

### 节点参数

**图像发布/客户端节点参数：**
- `cam_sn`：相机序列号（字符串）
  - 类型：`string`
  - 默认：`"None"`（连接第一个相机）
  - 设置方式：通过 launch 文件的 `<param>` 标签或 ROS 参数服务器

**点云客户端节点参数：**
- `pd_type`：点云类型（整数）
  - 类型：`int`
  - 取值范围：1-4
  - 默认：1
- `cam_sn`：相机序列号（字符串）

### 修改发布频率

默认发布频率为 30Hz（在源代码中设置）。如需修改，需要修改源代码中的：
```cpp
ros::Rate rate(30);  // 修改这里的数值
```

## 常见问题

### Q1: 如何查看相机是否连接成功？

**A:** 查看节点输出信息，成功连接会显示：
```
---------------- Connect by serial number: HK12345678 ----------------
[Publisher] Send depth image [0] success
```

### Q2: 如何查看所有可用相机？

**A:** 运行发布节点：
```bash
rosrun mv3d_rgbd_ros hik_camera_image_pub
```
节点启动时会枚举并显示所有相机的信息。

### Q3: 图像保存到哪里了？

**A:** 保存到运行 launch 文件时的当前工作目录下的 `image/` 文件夹。例如：
- 如果在 `~/workspace` 运行，图像保存在 `~/workspace/image/`
- 如果在 `~` 运行，图像保存在 `~/image/`

### Q4: 点云文件如何查看？

**A:** 可以使用 PCL 工具或 ROS 工具查看：
```bash
# 使用 pcl_viewer（需要安装 PCL 工具）
pcl_viewer point_cloud/0_point_cloud.pcd

# 或在 ROS 中发布点云话题，用 Rviz 查看
rosrun pcl_ros pcd_to_pointcloud point_cloud/0_point_cloud.pcd _frame_id:=camera_link
```

### Q5: 多相机时如何区分不同相机的数据？

**A:** 
- 在服务模式下，保存的文件名包含帧号，可以通过帧号区分
- 服务器日志会显示相机序列号，例如：`[Server] SN:HK12345678 Save [0]_RgbImage.png success`

### Q6: 如何停止采集？

**A:** 按 `Ctrl+C` 停止 launch 文件，节点会自动停止相机并关闭连接。

## 技术架构

### 通信模式对比

| 模式 | Launch 文件 | 优点 | 缺点 |
|------|-----------|------|------|
| 发布-订阅 | `capture_and_save.launch`<br>`connect_by_serial_number.launch` | 简单、实时性好 | 数据可能丢失 |
| 服务通信 | `multiple_camera.launch`<br>`obtain_point_cloud.launch` | 可靠、支持多客户端 | 可能有延迟 |

### 节点关系图

**发布-订阅模式：**
```
相机 → hik_camera_image_pub → ROS话题 → hik_camera_image_sub → 保存图像
```

**服务通信模式：**
```
相机1 → client1 ┐
相机2 → client2 ├→ SaveImage服务 → server → 保存图像
相机3 → client3 ┘
```

## 总结

`mv3d_rgbd_ros` 功能包提供了完整的 3D RGB-D 相机控制方案：

2. **灵活配置**：`connect_by_serial_number.launch` 支持指定相机
3. **多相机支持**：`multiple_camera.launch` 支持多相机同步
4. **点云采集**：`obtain_point_cloud.launch` 支持多种点云格式

根据你的需求选择合适的 launch 文件即可！
